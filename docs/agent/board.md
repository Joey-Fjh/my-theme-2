- **Header dropdown parent renders `<a href="">` inside `<summary>` (found in the `abstraction-boundaries.md` review, 2026-09-22).** `snippets/header-dropdown-menu.liquid:36` calls `render 'link'` without `href`, inside `<summary class="dropdown-trigger">`. With JavaScript, `onMenuTriggerClickEvent` (`assets/alpine.components.ui.js`) prevents the click and toggles the menu. The markup is valid HTML (`<summary>` allows phrasing content, including `<a>`), but it is an accessibility risk: `<summary>` has no fixed ARIA role in the spec, some browsers expose it as a button, and a focusable element inside a button-like control is the pattern axe's `nested-interactive` rule targets. Whether axe reports this instance is untested. It does add a second tab stop. Unverified in a browser: without JavaScript, a click on the text may follow `href=""` and reload the page instead of opening the menu. The likely fix renders the title as plain text inside the summary. This is code in an accepted primitive (header nested-menu dropdown) and needs a browser pass.

Current state: of 15 sections, only `custom-section` accepts `@theme`; `footer` uses section blocks; `product` accepts `@app` only; the other 12 have no blocks. No `templates/*.json` or `config/settings_data.json` currently places it.

## Settled here, not yet migrated

- **The Batch SOP stays in `AGENTS.md` (A, user 2026-09-22).** Workflows are the most effective content in an agent entry file and belong in it, because the entry file is always read while referenced docs are read about 90% of the time (Augment Code study). Claude Code guidance: the entry file is advisory; rules that must always hold become hooks or lint. A later trim toward 150 lines is optional. Sources: https://www.augmentcode.com/blog/how-to-write-good-agents-dot-md-files, https://code.claude.com/docs/en/best-practices.
